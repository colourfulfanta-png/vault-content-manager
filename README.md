# Vault · 个人密码与资产保管库

跑在 **Cloudflare Workers + D1** 上的单用户个人保险库：存密码、域名、服务器、笔记等。
敏感字段在浏览器端用主密码派生的 AES-256-GCM 加密，**服务器全程不接触主密码**。

- 前端：原生 HTML/CSS/JS（无框架、无构建步骤），由 Workers Static Assets 托管
- 后端：Hono（TypeScript，`src/index.ts` 单入口）
- 数据库：D1（SQLite）
- 本地开发：`wrangler dev`（本地 D1，完全离线）

线上实例：部署到你自己的 Cloudflare 账号（详细步骤见 [README.agent.md](README.agent.md)）

> 部署 / Cloudflare 配置 / Git 入门 / 故障排查详见 **[README.agent.md](README.agent.md)**；
> 只想本地运行（不需要 Cloudflare 账号）请用 **`local` 分支**，里面带一键启动脚本。

## 功能

- **登录 / 注册智能判断**：不存在的用户名自动切换"创建账号"模式；已有账号只输一次主密码即可登录
- 自定义类型：字段名、类型（字符 / 长文本 / 数值 / 枚举 / 网址）、是否加密、是否必填
- 条目增删改查、详情弹层、密码字段打码 / 👁 切换
- **一键复制**：详情里每个字段右侧 📋（标题除外），加密字段直接复制已解密值
- **置顶**：卡片右上角 📍/📌 切换，置顶条目排最前（存在 `plain._pin`，无需数据库迁移）
- **快捷键**：`/` 聚焦搜索、`n` 新建条目（输入框/弹窗内不触发）
- **品牌定制**：登录页标题/副标题 + 主界面 Logo 可自定义（保存在本浏览器 localStorage）
- 背景与主题：纯色 / 渐变 / 图片（cover / stretch / contain）、透明度、深浅色主题
- 加密备份导出 / 导入（便携格式，可跨实例迁移）
- **恢复码找回**：忘记主密码时可重设并重加密全库
- 账号安全面板：密保邮箱（改邮箱需验证主密码）、生成/重新生成恢复码
- 条目按条写入 + 乐观冲突检测（多标签页/多设备不互相覆盖）
- 写失败回滚提示，不会"假装保存成功"

## 加密与认证设计

```
主密码（仅浏览器内存 / sessionStorage，关标签页即失效）
  ├─ authKey  = PBKDF2(主密码, auth盐, 310000) → SHA-256 → verifier（服务器只存这个）
  ├─ encKey   = PBKDF2(主密码, enc盐, 310000)  → AES-256-GCM 加密条目敏感字段（密钥不出浏览器）
  └─ backupKey= PBKDF2(主密码, 固定盐 'vault-backup-v2', 310000) → 加密备份文件（跨实例可解）
```

- 两个独立的盐：D1 泄露后，攻击者每个候选密码要做两次 PBKDF2 才能同时验证登录并尝试解密
- 服务器只存：用户名、verifier、两个盐、迭代次数、条目密文、恢复码 blob —— **没有可逆凭据**
- **恢复码**：注册时把 `encKey` 用恢复码派生密钥再包一层（`recovery_blob` + `recovery_verifier`），
  服务器没有恢复码解不开；找回时客户端解出 encKey，用新主密码重加密全库并原子提交 → 零知识不降级
- 旧版账号（scheme=1）首次登录会由前端自动原子升级到新方案

## 登录 / 注册（智能判断，纯前端）

- 输入用户名后自动检测（失焦或停顿 600ms）：
  - 账号存在 → 登录模式，确认密码框隐藏，只输一次主密码
  - 账号不存在 → 自动勾选「创建新账号」，显示确认密码框
- 判断错了可以手动勾选/取消「创建新账号」来纠正
- 提交时若发现用户名不存在且未在创建模式，会自动切换并提示补输确认密码（不会报"解析错误"）

## 使用小技巧

| 操作 | 方式 |
|---|---|
| 复制某字段 | 打开条目详情 → 字段右侧 📋 |
| 置顶条目 | 卡片右上角 📍 |
| 搜索 | 按 `/` 或点顶栏搜索框 |
| 新建条目 | 按 `n` 或点「＋ 新建条目」 |
| 关闭弹窗 | `Esc` / 点遮罩 / 「关闭」 |
| 自定义品牌 | 🛡️ 账号安全 → 品牌 → 保存（本浏览器生效） |

> 品牌保存在本浏览器 `localStorage`（和背景/主题一致），换设备不会同步。

## 备份 / 恢复

右上角 **💾** → 「导出备份」生成加密 JSON（加密字段在信封内还原后，用**只由主密码派生的备份密钥**加密，
与服务器盐无关）。导入时用目标实例密钥重新加密写入。
**主密码丢失 = 备份无法解密**，请妥善保存主密码与恢复码。

## 迁移 / 换实例（本地 → 云端）

1. 旧实例：**💾 → 导出备份**
2. 新实例：用**同一个用户名 + 主密码**登录一次（空库会自动创建账号；保存恢复码）
3. 新实例：**💾 → 导入备份**

## 忘记主密码（恢复码找回）

1. 登录页点「忘记主密码？用恢复码找回」
2. 输入用户名 + 恢复码 + 新主密码（两遍）
3. 客户端解出旧数据密钥 → 新主密码重加密全库 → **D1 batch 原子提交**
4. 成功后显示**新的恢复码**（旧恢复码作废），请保存

> 恢复码只显示一次；丢失且忘记主密码 = 数据无法找回。

## 本地开发

```bash
npm install
cp wrangler.toml.example wrangler.toml                    # 首次：从模板创建（Windows: copy ...）
npx wrangler d1 execute vault --local --file schema.sql   # 首次或换库后执行
npx wrangler dev                                          # → http://localhost:8787
```

> 本地 D1 数据文件按 `wrangler.toml` 中的 `database_id` 区分；换 id 等于换库。
> 多环境可用 `--persist-to <目录>` 指定独立状态目录。

## 部署到 Cloudflare

```bash
npx wrangler d1 create vault                 # 把返回的 database_id 填进 wrangler.toml
npx wrangler d1 execute vault --remote --file schema.sql
npx wrangler secret put JWT_SECRET           # 建议设置
npx wrangler deploy
```

旧库升级需按顺序执行 `migrations/` 下的 SQL（每个只跑一次）。

部署完成后可在 Cloudflare 控制台绑定自己的自定义域名（见 [README.agent.md](README.agent.md)）。

## 安全与运维

- **登录限速（推荐用 Cloudflare 控制台，零代码）**：
  Security → WAF → Rate limiting rules，新建规则：
  - 匹配：`URI Path` 等于 `/api/auth/login` 或 `/api/auth/recover/verify`
  - 阈值：同一 IP 10 次 / 分钟；超出动作选 Block（或 Managed Challenge）
  - 免费计划有额度，够个人使用
- 代码版限速（D1 记失败次数 → 429）已列为待办，暂未实现
- 公网部署建议再加 Cloudflare Access（Zero Trust）做一层访问控制

## 已知限制 / 暂未实现

- 不支持"直接修改主密码"（用恢复码重设即可，等价一次全库重加密）
- **邮箱找回暂未启用**：邮箱验证码发送、邮箱找回数据（需把可解密材料交给服务端，会降低零知识）暂不做；
  当前找回方式为**恢复码**（保持零知识）。密保邮箱目前仅作账号标识/提醒
- R2 附件功能暂缓（已用"一键复制"替代常用需求）
- 登录限速目前建议在 Cloudflare 控制台配置（见上），未内置代码版
- 无回收站/撤销删除；备份恢复为整库覆盖；类型保存仍是整表替换（类型少，风险低）
- Firefox 下密码掩码不完美；免费版 Workers 跑 PBKDF2 需留意 CPU 限制
